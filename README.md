# FORMA · BlazorCAD

.NET 10 Blazor Web App，采用 Interactive Server（Blazor Server）。项目启动为空白。

## 建模流程

1. 已选中实体平面时，点击顶部“新建草图”直接在该面创建并自动正对一次。未选实体面时，点击“新建草图”才显示蓝色 XY、绿色 XZ、红色 YZ 网格面，选面后创建草图。选择树中的草图或图元不会被当作预选实体面。
2. 拖动绘制矩形或圆。尺寸标注可选：使用标注工具点击图元边，右侧输入尺寸。
3. 结束草图，视角保持不变。系统按交点分割轮廓，识别独立封闭区域。
4. 悬停区域高亮，点击选择；Ctrl / Shift 加选。右侧也可以勾选区域、全选或清除。
5. 点击拉伸或切除，选择“指定距离 / 贯穿全部 / 到指定面”。预览中点击区域可增减选择，确认后才写入特征。

例如圆跨过矩形边时，圆在矩形内的部分、矩形外的部分以及剩余矩形区域可分别选择。矩形内完整的圆形成独立圆区域，同时成为周围区域的孔边界。相邻区域一起选中时，公共边界会消除，按组合后的区域生成特征。

不再要求“必须先标注、再选标注边”才能拉伸或切除。尺寸用于驱动草图形状，区域用于定义特征范围，两者分别处理。

左侧历史树中草图下的矩形/圆用于编辑图元；在草图结束后点击图元，会选中该图元内部的全部区域。要选交叉形成的局部区域，请直接点画布或右侧区域列表。

## 交互

- 顶部工具栏集中提供草图流程、草图几何、实体特征和视图命令。“新建草图”和“结束草图”始终位于同一组；右侧仅处理参数、区域及特征确认，不再重复放置绘图入口。
- 左侧为可折叠的建模历史树：零件 → 实体结果 → 按顺序生成的拉伸/切除 → 来源草图 → 矩形/圆。未生成特征的草图保留在零件下；共享草图以引用方式显示，避免伪造独立实体。
- 点击历史步骤可查看其来源草图和终止条件，点击草图或图元可继续选择、编辑。折叠由树节点前的箭头控制。
- 完成切除后，仍可展开“特征 → 草图 → 圆 → 直径”，点击尺寸节点后直接在右侧改值；也可点击圆或矩形，直接修改尺寸和局部 X/Y 位置。修改会依次重建已存在的特征，不要求先重新进入草图。
- 双击草图或点击其编辑图标进入绘图状态；双击图元进入所属草图。绘图期间暂时显示该草图生成特征之前的实体，结束后恢复完整结果，避免拿切除后的孔边作为原承载面。
- 双击拉伸/切除，或点击该步骤的编辑图标，可修改距离、方向和终止条件。确认更新原特征并保留标识，然后重建后续步骤；取消不改变特征。
- 悬停与选择着色在浏览器本地更新，悬停不请求服务器。
- 单纯改变选择复用现有画布几何，不重新构建实体。
- Esc 返回选择工具，预览时 Esc 取消特征。
- 结束草图后保持当前视角，底部按钮可正对草图、等轴测或适合窗口。
- 每次新建草图，选择承载面后自动正对一次；此后的参数修改、绘图和选择不自动拉回视角。中键可随时旋转、右键平移、滚轮缩放；选择工具下左键也可拖动旋转。底部“正对草图平面”按钮可随时重新对齐，不锁定后续旋转。
- 底面为世界 XY 方向的镜面舞台，具有轻微模糊倒影和阴影，没有栅格。底面仅随实体包围盒调整高度和中心，选面不会让底面旋转或贴附到面上。
- 不显示实体网格边线和预览线框。只有新建草图的选面阶段显示三张彩色网格面，此时临时隐藏镜面底面以免遮住基准面；选定后隐藏三张网格、恢复镜面底面。实际草图线及尺寸标注保留。
- 实体平面可承载后续草图；不支持曲面草图。
- 支持撤销、重做、项目保存/打开及毫米单位 STL 导出。有效修改自动保存到后端，刷新后恢复最近项目。

拉伸默认沿草图法线正向，切除沿相反方向进入实体，两者都可勾选“反向”。特征保存选中的区域标识和来源图元，重建时按草图重新计算边界。普通尺寸修改维持交叉拓扑时可以重建；如果交点增减导致区域失效，提示重新选择，避免静默替换为整个矩形或圆。

## 绘图吸附

绘制圆或矩形时，支持吸附承载面的顶点、直线边中点、轮廓中心和面中心，以及当前草图的矩形顶点/中点、圆心、原点。屏幕距离 12 像素内显示黄色吸附标记与类型；例如圆心靠近立方体面的左上角时，命中真正的面顶点，使用其精确局部坐标。

面边界会先合并三角形公共边，避免把内部对角线、直线上的细分点当作吸附顶点。中键旋转时暂停吸附，Alt 暂时关闭几何吸附；未命中时仍采用 1 mm 网格。吸附绘制的起点和终点会保存重合关系；圆的起点绑定圆心，终点绑定点在圆上。实体顶点通过相邻平面的引用定位，修改上游尺寸后重新计算。引用失效或约束冲突时拒绝修改并保留原图，不会静默解除关系。

## 特征终止条件

- 指定距离：输入 1–1000 mm。
- 贯穿全部：依据当前方向与已有实体的包围范围计算深度，留有越界余量；父特征改变后重新计算。需要已有实体，首个特征请使用指定距离。若当前方向没有实体，可使用反向。
- 到指定面：在画布拾取已有实体的平面，蓝色高亮为终止面。各个顶点沿拉伸方向与目标平面求交，形成与目标平面对齐的端面；支持斜平面。这里以该面的支撑平面作为终止面，不按有限面片的边界裁剪横向范围。目标面需来自更早特征且仍存在，曲面暂不支持。

预览面板显示终止条件和有效距离。未选终止面、目标平面与拉伸方向平行、目标在反方向或穿过起始轮廓时，不允许确认；可以反向或重新选择终止面。拾取期间可随时旋转视角，Esc 先退出拾取，再按 Esc 取消特征。

## 实现范围

目前图元为矩形、圆、任意方向长圆槽和虚线参考线。长圆槽为两段半圆与两条平行直边，总长不得小于槽宽，圆弧使用离散线段参与区域计算。参考线不进入区域与实体计算。区域识别对线段/线段、线段/圆、圆/圆求交，构建平面半边图；孔洞和相邻区域合并共用这套边界数据。渲染和实体仍使用离散网格，布尔运算为 BSP，不包含完整几何约束求解器、自由曲线或 STEP/B-rep 内核。极近相切、重合及复杂连续布尔运算的数值稳健性需要继续调试，不能等同于 SolidWorks 的完整建模内核。

项目格式保留 version 2，包含 RegionKeys / SourceEntityIds、EndCondition、Reversed 和 TargetFace。旧文件缺少终止条件时默认指定距离。

Three.js 0.180.0 本地分发，许可证在 `wwwroot/vendor/THREE-LICENSE.txt`。界面使用系统字体，不加载外部字体资源。

## 草图约束与拖动

- 草图编辑中切换到“选择”：拖动圆周调整直径，拖动矩形边调整相应大小，长圆槽两端调整总长、两条直边调整槽宽。中心控制点或 Shift 拖动用于移动图元。
- 右侧“几何约束”可固定圆心、矩形/槽的中心或包围框角点、参考线起点/终点。固定点保持在当前草图坐标，修改尺寸时同样保留此点。
- 尺寸标注作为驱动约束，拖动不改变已标注的大小。圆心和直径都固定时圆不能拖动；仅直径固定时拖动圆可移动。可选中尺寸后解除约束，或输入新值修改约束值。
- 参考线为虚线，支持端点/中点吸附及长度标注。未锁定长度时拖动改变端点；长度固定而端点未固定时移动整条线，固定一个端点后可绕它旋转。
- 参数与固定点随项目保存、撤销/重做；拖动期间使用本地预览，松开后提交一次，重新计算历史特征，失败时恢复原数据。

当前支持固定点、手动尺寸、吸附绘制的点重合及平行直边距离约束；尚未实现通用平行、相切和相等约束。参考线支持自身长度标注，以及圆心、矩形/长圆槽中心到参考线的有向距离约束；在图元属性选择参考线后输入距离，正负表示参考线两侧。距离约束保留沿线方向的移动自由度，参考线修改后关联图元重定位并重建。与固定点冲突时拒绝修改。平行直边之间的尺寸通过智能尺寸依次选择两条边建立。


## 草图可见性与尺寸排布

- 草图树旁的眼睛按钮可隐藏/显示草图，包括尚未拉伸的草图。隐藏只影响草图与标注显示，不影响实体和特征引用；编辑草图时会自动显示，正在编辑的草图不能隐藏。显示状态随项目保存并支持撤销。
- 每个图元在属性里提供几何参数：矩形宽/高、圆直径、长圆槽总长/槽宽、参考线长度。绘制完成不自动生成尺寸标注，修改属性参数也不自动添加约束；只有明确添加尺寸标注才锁定相应尺寸。解除标注后恢复对应的大小自由度。已有项目中保存的手动标注仍保留。
- 选择工具下拖动标注文字或尺寸线可调整排布，支持手动尺寸和参考距离。拖动期间在画布本地更新引线、箭头与文字，松开时记录一次撤销；Esc 取消。移动标注不改变实体或约束。标注位置按相对自动位置的偏移保存，图元移动/变大后仍跟随。右侧可恢复标注自动位置。
- 编辑已有草图时默认选中图元，右侧直接显示尺寸；多个图元可从属性下拉框切换。编辑历史拉伸/切除时可点击“编辑来源草图尺寸”。

## 边框拖动与编辑对比度

- 草图实体轮廓增加屏幕宽度描边，避免 WebGL 单像素线过细；未选中为亮蓝，选中为橙黄，控制点为白色，固定锚点为橙色。参考线保留虚线。
- “选择”工具可直接拖边及控制点，不需要从中心移动代替拖边。边框按屏幕像素拾取，缩放远近不会把拾取范围压缩到难以操作。
- 矩形边按法向调整对应大小，角点可以同时调整两轴。固定中心时围绕中心对称缩放，固定角点时保持该角点；拖动与锚点重合的受限边不会挪动锚点。
- 对应大小已被驱动尺寸约束时，拖边改为移动整个图元（位置未固定时）；圆直径固定后拖圆周移动圆心，圆心固定后拖圆周只改半径，两者都固定则不动。中心控制点/Shift 用于显式移动，固定点会禁止平移。
- 参考线端点可分别拖动，长度固定后可平移，固定一个端点后拖另一端可以绕锚点旋转；长圆槽左右端调整总长，上下边调整槽宽。
- 拖动时实际轮廓、控制点和标注一同本地更新，松开后提交一次历史变更。悬停显示可缩放/移动/锁定的光标与动作说明，Esc 恢复原状。仅静态检查，未编译运行或执行测试。

新建图元后自动切换为选择工具，可立即拖动边框；绘制预览与已有轮廓均使用加粗描边。拖动按显示帧刷新，避免高频鼠标事件反复重建显示对象。

## 断连、空白视图与草稿恢复

静态排查发现两条确定的丢失路径：默认重连脚本在 rejected/恢复失败时自动刷新，而项目此前只保存在 Home 组件内存中；Three.js 更新也会先销毁旧场景，后续构建异常时只剩空画布。已改为显式恢复连接，并在新场景成功创建后才销毁旧场景，失败时还原上次显示状态。

每次通过校验的修改及撤销/重做，都会向当前标签页的 sessionStorage 写入项目草稿；重新进入页面时先读取、校验并恢复。只保存完成的操作，不包含尚未确认的输入、拖动或特征预览，也不保存撤销栈。新建项目会用空项目替换当前标签页草稿。恢复以标签页为单位，关闭标签页后不保证保留，不能代替手动保存项目文件。草稿上限 2 MiB，配额或写入失败会在状态栏提示并保留上一份备份；服务端接收上限设为 4 MiB，以容纳草稿和区域元数据。

重连失败界面与编辑错误栏可下载恢复草稿和诊断记录；仅用户点击“恢复草稿并重新连接”后才会重新加载页面。浏览器记录最近 30 条错误/连接状态，服务端记录视图失败、编辑回滚与超时；没有实际运行日志，尚不能认定是哪一个事件首次触发断连。额外捕获视图调用取消/超时，避免这些异常直接从界面操作中向外传播。

按要求未编译、未启动服务、未运行浏览器或测试，以上修复只做了静态核对。

编辑事务期间禁止另一个修改或撤销/重做重入，避免等待浏览器校验时交叉覆盖文档与恢复草稿；初始化恢复完成前同样不接受新修改。忙碌时给出状态提示，当前操作继续完成。


## 草图边与实体边的距离标注

在已有实体的平面上编辑草图，选择“智能尺寸”，依次点矩形边和承载面上的平行实体直边（顺序可交换）。先选边会高亮，悬停的实体边显示绿色。两边重合而难以区分时，按 Alt 优先选择实体边。智能尺寸支持单边尺寸，或两条不同直线的间距；选中第一条草图边后，尺寸预览随鼠标移动；选择第二条平行直边后切换为两边间距。点击空白放置预览并输入数值，Enter 确认，Esc 或输入框外的空白取消并重新选边。

新标注是可编辑的距离约束：双击数字修改、拖动调整排布，右侧及树中也可选中。没有固定点时优先通过移动矩形满足边距；两侧边距共同确定大小、或已有锚点限制移动时，可以调整未被驱动尺寸锁定的宽高；冲突则拒绝修改、保留原数据。标注随项目保存和撤销，并参与后续特征重建。引用通过承载面与相邻平面的身份确定，父实体尺寸变化后重新求边界；引用边被移除时提示失效，不静默换成另一条边。

当前支持“矩形直边—承载面真实平行直边”的线间距，包含多边形面上的直线段。曲边、非平行边的角度标注、跨离面边和任意两条草图边之间的距离尚未加入。实体边来自去除三角剖分内部线后的边界，不参与草图闭合区域。

尺寸线与箭头改为 6 CSS 像素外描边、引线 4.5 像素外描边，使用高对比颜色，避免 WebGL 原生线宽被限制为单像素；缩放不会把线宽缩细。原细线保留为不可见拾取对象，标注的文字编辑与拖动操作继续保留。

## 智能尺寸按两条线配对

连续点击第一条、第二条直线后创建间距，不再根据“第二条必须是实体边”替换选择。草图—草图与实体—草图均支持，两条都是实体边时不创建尺寸，也不修改已有实体。同一矩形的两条相对边同样可以配对，系统对应尺寸会让位给两边距离显示；反复点击同一条边不会新建标注，空白点击也不会把待选边转换为单边标注。

草图—草图默认以第一条线作参照、第二条所属图元为优先调整对象。跨图元的距离按连接关系整体求解，可结合已有边距、驱动尺寸、固定点与参考线约束；优先保持图元大小，通过移动满足距离，不能移动时才尝试未锁定的大小，冲突会拒绝并保留原模型。实体—草图只调整草图参数，形成参考边的已有特征不作为可变参数。

## 吸附关系与参数编辑

绘制时吸附到当前草图的顶点、中点、圆心、圆象限点或承载实体面的有效顶点/边中点/面中心，会保存引用而不是仅复制坐标。圆心重合后可调整半径；圆边界点吸附后保持该点在圆上。矩形角点重合后，尺寸改变仍保持该角点的关联。关系参与拖动预览、属性修改和上游特征重建，随文档、草稿和撤销记录保存。实体参照被删除或变得不唯一时提示重新关联。

编辑草图时可在属性中查看、解除点重合关系。普通属性参数表示当前形状，手动标注才表示尺寸约束；已有重合与尺寸约束优先，无法同时满足的编辑会回退。当前吸附建立关系发生在绘制图形时，拖动到某点不会自动新增重合约束。这仍是针对现有图元的约束求解，不是完整 SolidWorks 约束内核。

## 智能尺寸预览与圆弧中心

点击草图边后先显示随鼠标移动的尺寸预览：矩形边长、圆直径、参考线长度、长圆槽直边对应总长及圆弧对应槽宽。继续选择第二条平行直边，预览切换为两边间距；实体直边只能作为草图间距的参照，不创建实体自身驱动标注。空白处单击放置并弹出数值框，Enter 后一次性保存尺寸与位置；数值框出现后点空白或按 Esc 取消并重新开始。选错边也可右键或 Esc 清除选择。已有标注仍支持双击编辑和拖动排布。

## 中心长圆槽、共面侧面与性能

长圆槽从按下位置的正中心开始，拖向末端确定方向和总长，支持水平、垂直和任意斜向；初始槽宽取总长三分之一、最大 20 mm，可在属性中修改槽宽与方向角度。其吸附点、约束、控制点、尺寸线和拉伸侧面引用都使用同一旋转坐标。旧文档未保存角度时仍按 0° 读取。

对齐增材后，实体共面的侧面按一个连续平面高亮，草图参照边从共面表面整体边界提取，消除上下两次拉伸间的内部接缝；保留原特征引用，避免历史草图失效。

历史实体使用有上限的前缀缓存：从最近的未改变步骤继续重建，下游依赖改变时重新计算。尺寸文字位置和约束显示不参与实体几何缓存键。轮廓识别和实体参照边复用计算结果；修改时合并约束求解与几何校验，减少一次跨端往返和重复求解。实体拾取使用三角形空间树，只检查射线经过的范围。视图、草图和模型变化时重绘，静止时停止重复渲染镜面与阴影。BSP 布尔运算仍可能随复杂交叉和曲面细分产生大量面片，不能据此宣称大模型性能已经达到工业 CAD 水平。

## 交叉区域、普通直线与实体边吸附

矩形与长圆槽相交后，退出草图保留平面图中的全部有界闭合区域，包括矩形外侧的槽区域；不再用水平长圆槽的内部判断筛掉斜槽区域。开放的单根直线不产生实体区域，普通实线组成闭合回路后可选择拉伸或切除。

## 拉伸 / 切除深度游标

指定距离模式的特征预览提供三维方向箭头、可拖动游标和沿该轴投影的透明刻度尺。拖动箭头沿当前特征方向调整，视线接近正对该方向时改为上下拖动；刻度尺与箭头同向，沿轴投影方向拖动。默认每格 1 mm，按 Shift 以 0.1 mm 精调，支持方向键微调，范围 1–1000 mm。拖动中数值、刻度与预览同步，Esc 或指针取消撤回当前拖动；松开同步右侧参数，点击确认才生成特征。贯穿全部和到指定面继续由相应终止条件计算，不覆盖为手动距离。

深度拖动只对盲拉伸预览网格作沿法线的变换，不在每个鼠标事件重建历史实体；松开才同步一次 Blazor 参数。同步期间阻止确认旧值，操作或选区变化后拒绝过期回调。未编译、运行或执行测试。

深度刻度已移除面板背景、边框和独立横向尺，直接以透明线与数字显示在三维箭头旁。刻度位置由草图平面起点沿实际拉伸 / 切除轴投影计算，反向和旋转视角时随箭头变化，游标对应当前深度；长距离仅显示当前深度附近的刻度，数值仍以草图面为零点。视线正对轴线、无法投影出有效长度时隐藏刻度并提示旋转视角，避免显示虚假的横向尺度。未编译运行或测试。

## 扩展草图工具

- 扫描入口不再统一要求已选封闭区域。选中开放图元或草图后也能进入扫描，并在属性中分别指定截面草图和路径草图。若先选的是路径，可切换截面草图，原选择作为路径使用。
- 实体扫描：截面需要一个连通封闭区域（可带内孔），路径允许开放直线/圆弧/直线链，也允许闭合圆、椭圆或闭合直线链。
- 薄壁扫描：开放截面可用非参考直线、圆弧或连续无分叉直线链，设置 0.1–1000 mm 壁厚及对称/左侧/右侧加厚后生成实体，也支持扫描切除。当前开放截面最多 24 个有效采样点或拐点；闭合截面仍使用实体扫描模式。参考线可作为路径，但不作为薄壁实体的截面。
- 路径是否闭合与截面是否闭合分别判断；截面只提供形状、路径决定生成位置，两者无需相交或共面；保持原截面方向时，起始切线不能与截面平面平行（避免退化实体）。拉伸、旋转和放样目前的实体生成仍要求封闭截面，未实现开放截面的曲面特征。
- 新增薄壁参数、开放截面引用、厚度和加厚方向会写入历史和后端存档；历史中可重新编辑。未编译、运行或执行测试，仅作静态源码检查。


## 项目删除、扫描选择流程与实体旋转轴

- 顶部新增“删除项目”，后端项目列表每行也有删除图标。确认后删除主存档、备份和该编号下的损坏文件归档；保留不含模型内容的删除标记以阻止其他页面自动保存复活旧编号。刷新遇到已删除项目时跳过旧恢复草稿，清理引用并恢复其他项目或空白视图。删除需匹配已确认的后端版本，防止覆盖其他页面刚更新的内容。若存储权限不允许清理部分文件，项目仍被标记删除，残留清理错误记录在后端日志中。
- 扫描默认流程改为分别选择闭合截面与扫描路径：可先选闭合轮廓后点击竖线，也可先选竖线进入扫描，再选择闭合轮廓。开放直线不再自动切换为薄壁截面。路径可通过画布点击或属性选择，截面可通过画布闭合区域或下拉选择；路径不要求闭合。
- 扫描截面沿实际路径的各站位推进，方向采用平行传输。预览显示分层截面，并提供推进滑块和播放/暂停；推进预览仅改变显示，确认仍生成完整实体，不写入动画进度。开放路径使用曲线本身的起点，不根据原截面位置自动换端；反向切换起始端，截面重新定位到对应起点。
- 路径插值可选择跟随原始直线/圆弧/圆/椭圆/线链，或将连续直线链的顶点作为控制点生成平滑样条路径。样条插值由现有线链控制，不等同于新增完整样条草图编辑器。原薄壁扫描保留在“更多”中，作为明确选择的可选模式。
- 旋转轴可直接点选已有实体的直线棱边，也可使用草图线和 X/Y 轴。支持悬停、选中高亮和延长轴虚线；实体轴保存面引用而不是固定坐标，修改上游模型后重新解析该边。当前实体参照边须与旋转截面共面，不支持以圆弧边直接定义旋转轴。
- 实体轴引用和路径插值会参与后续重建、依赖删除、撤销及后端自动保存。遵循项目约定，本次未编译、运行或执行测试，仅进行静态源码核对。

### 扫描方向与中心路径
- 自动对齐先将截面中心移至路径起点，再旋转到起始切线的法向平面；保持原截面起始方向保留截面倾角，后续随路径转向。预览动画和最终实体共用相同的方向计算。
- 中心路径在关联截面中心的平面内创建直线，0° 沿截面法线，其他角度斜向延伸。源截面位置或尺寸变化时，路径原点随之更新。编辑该路径草图时显示原截面参考轮廓，原点吸附显示为“截面中心”。
- 中心路径的关联、截面方向选项随项目保存；删除源草图或关联轮廓时，删除依赖中包含中心路径和下游特征。
- 本轮仅修改源码并静态检查，未编译、运行或执行测试。

### 独立截面与路径的扫描定位
- 闭合截面和路径可位于任意不同位置与平面，无需相交。取所选截面外轮廓包围盒中心作为定位中心，保留轮廓、孔洞和尺寸，将中心定位到路径起点。原草图不移动、不复制。
- 实体网格与分层推进预览共用居中后的截面坐标；移动原截面不再产生路径之外的偏移。路径反向后会定位到新的路径起点。
- 默认操作是分别选择截面、路径后确认；从截面中心创建路径仅保留为折叠的可选辅助工具。

### 合并实体、空间旋转轴与截面列表

### 多边倒角／圆角、实体与材质
- “倒角 / 圆角”支持连续点选最多 32 条凸直棱边或平面与曲面相交的连续边界，再点取消。直倒角提供距离及 1–89° 角度，圆角提供半径（0.1–1000 mm）；采用圆弧截面生成切除工具，多条边的工具先做并集再统一切除。复杂曲棱、滚动球三边交汇不是当前实现范围。
- 左树新增按几何连接关系生成的实体分支，列出关联特征和独立材质；全部历史特征另保留在“建模步骤”，包括倒角／圆角，可编辑、删除。内部封闭空腔归属外围实体，不单列为空心内壳。
- 点击实体面或实体树选择实体，在属性中删除或按 Delete；删除计划联动清理关联特征、未共享的草图和失效约束，并显示影响列表，支持撤销和后端自动保存。共享特征的依赖也会列入删除影响列表。
- 内置工业摄影棚、车间、柔光三种程序化环境反射图，无外部网络依赖；可以关闭环境反射。实体使用物理材质，预设不锈钢、铝合金、铜、黄铜、铸铁、工业烤漆、工程塑料和橡胶。
- 材质参数按实体单独复制保存。颜色、金属度、粗糙度、高光、涂层、贴图物理尺寸和旋转均独立调整；两个相同预设的实体互不联动。
- 选中实体后上传 PNG/JPEG/WebP 颜色贴图（单张最多 8 MB），后端按内容哈希存储，不把图片嵌进 2 MB CAD 文档。刷新和服务重启后通过图片标识恢复，另存为仍引用同一持久文件。导出 STL 不包含材质，这是 STL 格式本身不支持材质。
- 自动 UV 默认以各面正交单位基底计算毫米坐标，不按单体包围盒分别归一化；另可选三向投射和法线混合柔化接缝。默认每 25 mm 图高重复一张，图宽自动按图片宽高比换算，避免非方形图片被拉成正方形；改变实体尺寸不会拉伸已有贴图，等密度模式下棋盘格在不同实体和平面上保持统一比例与物理密度；曲面按网格面自动映射可能有接缝，三向混合可柔化接缝。两种模式都不等于可导出展开的 UV 图集。
- 本轮仅源码编辑和静态检查，未编译、运行、启动服务或执行测试；几何交汇与视觉效果由用户调试验证。

### 材质质感与摄影棚反射调整
- 原来的 8 位色块环境改为线性半浮点 HDR 辐射图，保留超出白色的柔光箱亮度，经 PMREM 生成粗糙度对应的反射。布局包含主柔光箱、窄条轮廓光、背光与顶光，无外部网络依赖。
- 降低半球补光和方向灯强度，显式使用 sRGB 输出与 ACES 色调映射；接触阴影提高分辨率，地面贴近模型最低点，减少悬浮感。
- 不锈钢、铝合金等支持各向异性高光和方向控制，加入物理尺寸下的微弱粗糙度及法线变化；裸金属降低默认透明涂层，铸铁、塑料、橡胶使用不同细节强度。原实体已经保存的颜色、粗糙度等显式参数继续保留。
- 曲面及圆角仅对相邻兼容法线作面积加权平滑，平面和硬边保持原法线，不改变几何、尺寸和拾取结果。选中实体改为边缘轮廓提示，取消覆盖材质的整面颜色层。
- 每个实体新增拉丝强度、拉丝方向、微表面细节、环境反射强度，沿用独立保存和撤销。
- 本轮只做源码修改与静态检查，未编译、运行、渲染预览或执行测试；视觉结果仍需用户运行确认。

- 倒角／圆角预览显示布尔切除后的实体外形，沿用原实体的独立材质，隐藏原尖角显示；原实体仅继续用于棱边拾取，不作为红色切除工具叠加显示。

### 圆角接缝与观看中心
